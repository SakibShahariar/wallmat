# Wallmat

A keyboard-friendly wallpaper browser and chooser for Linux, built with **GTK 4** and **libadwaita**. Explore your wallpaper library in eight distinctive layouts, organize images into favorites and collections, preview them, and optionally apply a Material You color scheme with [Matugen](https://github.com/InioX/matugen).

## Features

- **Wallpaper library:** search, sort, filter by tags, and switch folders with drag and drop.
- **Personal organization:** favorites, named collections, recent wallpapers, and batch actions.
- **Preview and apply:** full-screen preview with zoom and pan, plus wallpaper application through the desktop's supported integration.
- **Material You theming:** optionally preview and apply colors generated by Matugen.
- **Automation:** timed rotation, random selection, applied-wallpaper history, and a plain command-line output mode.
- **Keyboard-friendly controls:** navigate and manage wallpapers without relying on the mouse.
- **Backup and recovery:** export and restore library metadata and preferences, with safeguards for invalid favorites data.

For detailed behavior and controls, see [Controls and features](docs/FEATURES.md). Supported formats, settings, and persistence are covered in [Configuration](docs/CONFIGURATION.md).

## Install and run

Install the GTK and Python bindings for your distribution.

**Debian / Ubuntu**

```sh
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1
```

**Fedora**

```sh
sudo dnf install python3-gobject gtk4 libadwaita
```

Optional WebP thumbnail support may require `webp-pixbuf-loader` from your distribution.

Run Wallmat from a source checkout:

```sh
python3 src/main.py ~/Pictures/Wallpapers
```

If no folder is supplied, Wallmat uses `/usr/share/backgrounds`. Choose a layout at launch with:

```sh
python3 src/main.py ~/Pictures/Wallpapers --layout infinite_ribbon
```

## Desktop integration and CLI

In normal UI mode, **Set as wallpaper** uses the XDG Wallpaper portal on Wayland and falls back to GNOME background settings only when the portal is unavailable. Other sessions use GNOME settings directly. Portal cancellation or failure is reported rather than bypassed.

To pass a selected wallpaper path to another command:

```sh
WP="$(python3 src/main.py ~/Pictures/Wallpapers --plain 2>/dev/null)"
matugen image "$WP" --type scheme-smart --mode dark
```

**Apply wallpaper + Matugen** runs Matugen as part of the workflow. Its arguments can be customized with `--matugen-args`. See the [Matugen and CLI guide](docs/FEATURES.md#matugen-and-cli-mode).

## Local data

Wallmat stores favorites, tags, collections, and preferences locally under `~/.config/wallmat/`. Favorites and tags can be included in backups; collection entries store paths, and adding a folder to a collection takes a snapshot of its current wallpapers.

See [Configuration](docs/CONFIGURATION.md) for data locations and backup details.
